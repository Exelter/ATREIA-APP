# Security Policy

## Supported Versions

Only the latest release of the Atreia App gets security fixes. The app updates itself on start, so keeping it up to date is enough. If you installed it a while ago and it hasn't updated, download the latest installer from https://atreia.app/go/app.

| Version          | Supported          |
| ---------------- | ------------------ |
| Latest release   | :white_check_mark: |
| Older releases   | :x:                |

This policy also covers the website (https://atreia.app) and the Atreia Discord bot.

## Reporting a Vulnerability

Please **don't** open a public issue, and don't post it on Discord.

Report it privately here on GitHub: go to the **Security** tab of this repository and press **Report a vulnerability**. Include what you found, how to reproduce it, and what someone could do with it.

What to expect:
- A first reply within a few days.
- If it's accepted, we fix it in the next release (as soon as possible for anything serious) and tell you when it's out. We're happy to credit you in the release notes if you want.
- If it's declined, we tell you why.

Please give us a reasonable time to fix it before telling anyone else. Don't access other players' data, disrupt the site or the bot, or test against accounts that aren't yours.
